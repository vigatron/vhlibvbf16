# Статистика реализации подмодулей на Xilinx XC6SLX9-144

## Спецификация FPGA (напоминание)

> **Примечание:** Все цифры — **оценки на основе ручного подсчёта по RTL-коду** (не синтез). Погрешность ±20–25%.

| Параметр | Значение |
|----------|----------|
| **LUTs (LUT6)** | 5,720 |
| **FF** | 11,440 |
| **DSP48A1** | 16 |
| **Block RAM** | 32 × 18Kb |

## Подмодули (Bottom-up)

### 1. `vhfastmulb16_mul4x4` — 4×4 multiplier (CSA tree)

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~45** | **0.8%** |
| FF | 8 | 0.1% |
| DSP48A1 | 0 | — |
| Latency | 1 cycle | — |
| Max Freq | ~350 MHz | — |

#### Архитектура (по колонкам CSA):
- 16 частичных произведений (AND `{4{a_i}} & b`): **16 LUT**
- CSA Level 1 (pp0+pp1+pp2, 6 значащих колонок: MAJ3=1 LUT + XOR3=1 LUT на колонку): **10 LUT**
- CSA Level 2 (+pp3, 7 колонок): **12 LUT**
- Финальный CPA 8-бит (carry chain CARRY4): **8 LUT**
- Выходной регистр: **8 FF**

---

### 2. `vhfastmulb16_mul8x8` — 8×8 multiplier (4× mul4x4)

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~210** | **3.7%** |
| FF | 48 | 0.4% |
| DSP48A1 | 0 | — |
| Latency | 2 cycles | — |
| Max Freq | ~250 MHz | — |

#### Архитектура:
- 4× `mul4x4` = 4 × 45 = **180 LUT**
- Финальное дерево сумматоров `(p_hh<<8) + (p_hl<<4) + (p_lh<<4) + p_ll`:
  3 adder по 8 бит (carry chain) = **24 LUT** (16-битный итог)
- FF: 4×8 (выходы `mul4x4`) + 16 (выходной регистр `c`) = **48 FF**

> **Примечание:** Можно заменить на 1× DSP48A1 (18×18) → `mul8x8` ≈ 0-10 LUT, экономия ~200 LUT (~95% модуля).

---

### 3. `vhfastmulb16_add8x8_lat2` — Exponent adder (a + b - 127)

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~18** | **0.3%** |
| FF | 19 | 0.2% |
| Latency | 2 cycles | — |
| Max Freq | ~400 MHz | — |

#### Архитектура:
- Stage 1: 9-битный сумматор `{1'b0,a} + {1'b0,b}` (carry chain) = **9 LUT**
- Stage 2: 9-битное вычитание константы 127 (carry chain) = **9 LUT**
- FF: `c_add` (9) + `c` (9) + `en_lat1` (1) = **19 FF**

### 8. `vhfastmulb16_except_lat2` — Exception handling (latency 2)

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~54** | **0.9%** |
| FF | 63 | 0.6% |
| Latency | 2 cycles | — |

#### Архитектура:
- 2× `flags_lat1` = **22 LUT / 10 FF**
- классификация (NaN/Inf/Zero с приоритетом): **~9 LUT**
- NaN payload mux (6 бит, приоритет A>B): **6 LUT**
- выходной mux `c` (16 бит; биты exp — из констант FF/Inf, биты payload — AND): **~14 LUT**
- `exval` и прочее: **1 LUT**
- FF: `a_d1`/`b_d1`/`en_d1` = 33, `c` = 16, `exval/ex_z/ex_inf/ex_nan` = 4 → **63 FF**

## Потенциал оптимизации

### 1. Использование DSP48A1 для mul8x8
| Подход | LUTs | DSP48A1 | Экономия |
|--------|------|---------|----------|
| Текущий (LUT-only) | ~210 | 0 | — |
| 1× DSP48A1 (18×18) | ~0-10 | 1 | **~200 LUTs (~95%)** |

> Spartan-6 имеет **16 DSP48A1**. Использование 1 для `mul8x8` сокращает RTZ top до **~200 LUTs (~3.5%)**.

### 2. Убрать избыточные mux `*_exp_eff`
- `a_exp_eff = a_is_subnormal ? 8'h00 : a_exp` логически эквивалентен `a_exp` (при субнормале exp=0).
- Экономия: ~16-30 LUTs на top-level (синтезатор может сделать это сам).

### 3. Объединение flags_lat1 + except_lat2
- Сейчас: 2× `flags_lat1` = 22 LUT внутри `except_lat2`.
- Объединение даёт скромную экономию ~10-20 LUTs (поглощение выходных регистров флагов).

**После оптимизаций RTZ: ~150-200 LUTs (~3%) — очень комфортно для XC6SLX9.**
