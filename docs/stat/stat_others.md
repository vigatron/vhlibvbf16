# Статистика реализации подмодулей на Xilinx XC6SLX9-144 (после рефакторинга)

## Спецификация FPGA (напоминание)

| Параметр | Значение |
|----------|----------|
| **LUTs (LUT6)** | 5,720 |
| **FF** | 11,440 |
| **DSP48A1** | 16 |
| **Block RAM** | 32 × 18Kb |

---

> **Важно:** Все цифры ниже — **оценки на основе ручного подсчёта по RTL-коду** (не синтез). Погрешность ±20–25%.

#### Правила подсчёта LUT6:
- любая булева функция от ≤6 входов = 1 LUT6;
- n-битный сумматор/вычитатель с carry chain (CARRY4) = n LUTs — перенос идёт через MUXCY, а не через LUT;
- 2:1 мультиплексор шириной n бит = n LUTs;
- сравнение ниббла с константой (NOR4/AND4) = 1 LUT.

## Подмодули (Bottom-up)

### 1. `vhfastmulb16_mul4x4` — 4×4 multiplier (CSA tree, latency 1)

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~45** | **0.8%** |
| FF | 8 | 0.1% |
| DSP48A1 | 0 | — |
| Latency | 1 cycle | — |
| Max Freq | ~350 MHz | — |

#### Архитектура (по колонкам CSA):
- 16 частичных произведений (AND `{4{a_i}} & b`): **16 LUT**
- CSA Level 1 (pp0+pp1+pp2, 6 значащих колонок: MAJ3=1 LUT + XOR3=1 LUT на колонку): **10 LUT**
- CSA Level 2 (+pp3, 7 колонок): **12 LUT**
- Финальный CPA 8-бит (carry chain CARRY4): **8 LUT**
- Выходной регистр: **8 FF**

---

### 2. `vhfastmulb16_mul4x4_lat2` — 4×4 multiplier, 2-stage pipeline (latency 2)

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~50** | **0.9%** |
| FF | 37 | 0.3% |
| DSP48A1 | 0 | — |
| Latency | 2 cycles | — |
| Max Freq | ~300 MHz | — |

#### Архитектура:
- Стадия 1: 3 частичных произведения (pp0, pp1, pp2) + CSA-1 (s1, c1) → регистры
  - 12× AND2 для частичных произведений: **~12 LUT**
  - CSA-1 на 10 бит (MAJ3 + XOR3): **~15 LUT**
  - Регистры стадии 1: s1(10) + c1(10) + a_lat(4) + b_lat(4) + en_lat1(1) = **29 FF**
- Стадия 2: pp3 + CSA-2 (s1 + c1 + pp3 → s2 + c2) + финальный CPA 10 бит
  - 4× AND2 для pp3: **~4 LUT**
  - CSA-2: **~15 LUT**
  - CPA 10 бит (carry chain): **~10 LUT**
  - Выходной регистр c (8 бит): **8 FF**
- **Итого LUTs:** 12 + 15 + 4 + 15 + 10 ≈ **~50**
- **Итого FF:** 29 + 8 = **~37**

> Отличие от `mul4x4`: конвейер разбит на 2 стадии с регистрами между ними. LUTs немного выше из-за дублирования логики промежуточных сигналов, FF значительно выше (37 vs 8) из-за pipeline регистров.

### 4. `vhfastmulb16_mul8x8` — 8×8 multiplier (4× mul4x4 + CSA tree, latency 2) [ОБНОВЛЁННЫЙ]

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~208** | **3.6%** |
| FF | 48 | 0.4% |
| DSP48A1 | 0 | — |
| Latency | 2 cycles | — |
| Max Freq | ~250 MHz | — |

#### Архитектура (после рефакторинга):
- 4× `mul4x4` = 4 × 45 = **180 LUT**, 4 × 8 = **32 FF**
- CSA-дерево (2 уровня CSA 3:2 + 1 финальный 16-битный CPA):
  - CSA Level 1 (P0+P1+P2 → s1 + c1, 16 бит): **~28 LUT**
  - CSA Level 2 (s1 + c1 + P3 → s2 + c2, 16 бит): **~28 LUT**
  - Финальный CPA 16 бит (carry chain CARRY4): **~16 LUT**
- Выходной регистр c (16 бит): **16 FF**
- **Итого LUTs:** 180 + 28 + 28 + 16 ≈ **~208**
- **Итого FF:** 32 + 16 = **~48**

#### До рефакторинга:
- 3 последовательных 8-битных carry-цепочки (CPA) = **24 LUT**
- Итого: **~210 LUT**

> Рефакторинг: заменена цепочка из 3 последовательных CPA на CSA-дерево (2 уровня CSA + 1 CPA). LUTs примерно те же (~208 vs ~210), но критический путь короче (нет последовательных переносов через 3 сумматора).

### 5. `vhfastmulb16_mul8x8_lat3` — 8×8 multiplier (4× mul4x4_lat2 + CPA, latency 3) [НОВЫЙ]

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~230** | **4.0%** |
| FF | 160 | 1.4% |
| DSP48A1 | 0 | — |
| Latency | 3 cycles | — |
| Max Freq | ~220 MHz | — |

#### Архитектура:
- 4× `mul4x4_lat2` = 4 × 50 = **200 LUT**, 4 × 37 = **148 FF**
- Финальный CPA 16 бит (carry chain): **~16 LUT**
- Выходной регистр c (16 бит): **16 FF**
- enable pipeline (en_s1, en_s2): **2 FF**
- **Итого LUTs:** 200 + 16 ≈ **~230**
- **Итого FF:** 148 + 16 + 2 = **~166** (в сводных таблицах округлено до **~160**)

> Используется как альтернативный 8×8 множитель с 3-стадийным конвейером.

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~11** | **0.2%** |
| FF | 11 | 0.1% |
| Latency | 2 cycles | — |

#### Разница с lat1:
- те же 6 ниббл-сравнений: **6 LUT**

### 11. `vhfastmulb16_except_lat2` — Exception handling (latency 2) [БЕЗ ИЗМЕНЕНИЙ]

| Ресурс | Оценка | % LUTs |
|--------|--------|--------|
| **LUTs** | **~54** | **0.9%** |
| FF | 63 | 0.6% |
| Latency | 2 cycles | — |

#### Архитектура:
- 2× `flags_lat1` = **22 LUT / 10 FF**
- классификация (NaN/Inf/Zero с приоритетом): **~9 LUT**
- NaN payload mux (6 бит, приоритет A>B): **6 LUT**
- выходной mux `c` (16 бит; биты exp — из констант FF/Inf, биты payload — AND): **~14 LUT**
- `exval` и прочее: **1 LUT**
- FF: `a_d1`/`b_d1`/`en_d1` = 33, `c` = 16, `exval/ex_z/ex_inf/ex_nan` = 4, 2× `flags_lat1` = 10 → **63 FF**
