# Статистика реализации на Xilinx Artix-7 (XC7A15T)

## Спецификация целевого FPGA

| Параметр | Значение |
|----------|----------|
| **Device** | XC7A15T (Artix-7) |
| **Package** | varies (CPGA196, etc.) |
| **Slices** | 2,600 |
| **LUTs (6-input / LUT6)** | **10,400** (2,600 × 4) |
| **Flip-Flops** | 20,800 |
| **Block RAM (36Kb)** | 25 (900 Kb total) |
| **DSP48E1** | 45 |
| **Max Clock (typical)** | ~250–450 MHz для простых путей |

---

> **Важно:** Все цифры ниже — **оценки на основе ручного подсчёта по RTL-коду**. Реальный синтез в Xilinx Vivado не выполнялся, отчётов синтеза нет. В `logs/` и `build/` могут находиться артефакты симуляции. Погрешность ручного подсчёта для Artix-7 — **±20–25%**.

#### Правила подсчёта LUT6:
- любая булева функция от ≤6 входов = 1 LUT6;
- n-битный сумматор/вычитатель с carry chain (CARRY4) = n LUTs — перенос идёт через MUXCY, а не через LUT;
- 2:1 мультиплексор шириной n бит = n LUTs;
- сравнение ниббла с константой (NOR4/AND4) = 1 LUT.

## Критический путь (Timing)

### RTZ:
```
mul4x4 (CSA) → mul8x8 CPA → exp_sum + man_msb → c_next mux → output reg
```
~4.0–4.5 ns (220–250 MHz)

### RNE:
```
mul4x4 (CSA) → mul8x8 CPA → man_shifted/G/R/S → RNE increment → exp_norm → c_next mux → output reg
```
~4.5–5.0 ns (200–220 MHz)

### F32:
```
mul4x4_comb (CSA) → CPA → leading-one → mant_norm shifter
→ exp_unb → F32 pack mux → output reg
```
~4.5–5.2 ns (190–220 MHz)

## Рекомендации по оптимизации

| Оптимизация | Экономия LUTs | Сложность |
|-------------|---------------|-----------|
| Перенести `mul8x8` на DSP48E1 | ~-200 LUTs | 1× DSP48E1 (25×18 multiplier) |
| Убрать избыточные mux `*_exp_eff` | ~-16 LUTs | Простейшая правка |
| Объединить `except_lat2` + `flags_lat1` | ~-10 LUTs | Рефакторинг флагов |
| **Потенциальный итог RTZ** | **~170-220 LUTs (~1.6-2.1%)** | |

> Artix-7 XC7A15T имеет **45 DSP48E1**. Использование 1 для `mul8x8`
> сокращает RTZ top до **~190-240 LUTs (~1.8-2.3%)**.
