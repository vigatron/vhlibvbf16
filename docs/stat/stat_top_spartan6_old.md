# Статистика реализации на Xilinx XC6SLX9-144 (Spartan-6 LX9)

## Спецификация целевого FPGA

| Параметр | Значение |
|----------|----------|
| **Device** | XC6SLX9 (Spartan-6 LX9) |
| **Package** | CSG144 / CPG144 |
| **Logic Cells** | 9,152 |
| **Slices** | 1,430 |
| **LUTs (6-input / LUT6)** | **5,720** (1,430 × 4) |
| **Flip-Flops** | 11,440 |
| **Block RAM (18Kb)** | 32 (576 Kb total) |
| **DSP48A1** | 16 |
| **Max Clock (typical)** | ~200-300 MHz для простых путей |

---

> **Важно:** Все цифры ниже — **оценки на основе ручного подсчёта по RTL-коду**. Реальный синтез в Xilinx ISE/Vivado не выполнялся, отчётов синтеза нет. В `logs/` и `build/` могут находиться артефакты симуляции. Погрешность ручного подсчёта для Spartan-6 — **±20–25%**.

#### Правила подсчёта LUT6:
- любая булева функция от ≤6 входов = 1 LUT6;
- n-битный сумматор/вычитатель с carry chain (CARRY4) = n LUTs — перенос идёт через MUXCY, а не через LUT;
- 2:1 мультиплексор шириной n бит = n LUTs;
- сравнение ниббла с константой (NOR4/AND4) = 1 LUT.

## Top-level модули

### 1. `vhfastmulb16_rtz_lat3` (RTZ — Round Toward Zero)

| Ресурс | Оценка | % от доступных (5,720 LUT6) |
|--------|--------|----------------|
| **LUTs** | **~400** (350–450) | **~7%** |
| FF (регистры) | **~150** | **~1.3%** |
| DSP48A1 | 0 | 0% |
| Block RAM | 0 | 0% |
| **Макс. частота** | ~180 MHz | — |

#### Распределение по подмодулям:

| Подмодуль | LUTs | FF | Примечание |
|-----------|------|-----|------------|
| `mul_u8_u8_u16_lat2` (4× `mul4x4` + дерево сумматоров) | ~210 | 48 | 4× CSA-структура + 3 carry-chain adder (8+8+8 бит = 24 LUT) |
| `add8x8_lat2` | ~18 | 19 | 9-bit add + 9-bit sub (константа 127), carry chain |
| `sign` | ~1 | 3 | 1 XOR (частично поглощается LUT соседней логики) |
| `except_lat2` (включая 2× `flags_lat1`) | ~54 | 63 | флаги, классификация NaN/Inf/Zero, NaN payload mux |
| **Top-level glue** (FTZ, mux, exp_norm, c_next) | ~120 | 18 | деталь ниже |
| **ИТОГО** | **~400** | **~150** | |

#### Детали glue-логики RTZ (~120 LUTs):
- FTZ-детектирование (exp==0 && frac!=0): 2× ~7 = **14 LUT**
- mux `*_eff` (exp 8 бит + frac 7 бит): 2× 15 = **30 LUT** (синтезатор частично свернёт: `a_exp_eff ≡ a_exp`, т.к. при субнормале exp=0)
- mux мантисс `a_man`/`b_man`: 2× 8 = **16 LUT**
- `exp_norm` = exp_sum + man_msb (9-битный инкремент, carry chain): **9 LUT**
- компараторы under/overflow (9-бит vs константы 381/254): **~11 LUT**
- mux `man_norm` (7 бит): **7 LUT**
- приоритетный mux `c_next` (5 ветвей × 16 бит): **~32 LUT**
- `en_pipe` и прочее: **1 LUT**

#### Разница с RTZ (+30 LUTs):

| Компонент | Доп. LUTs | Причина |
|-----------|-----------|---------|
| man_shifted mux + G/R/S/LSB extract | +13 | выбор нормализованной мантиссы и битов округления |
| Инкремент man_shifted при round_up (8 бит + carry) | +12 | в коде явный ripple-инкремент; синтезатор свернёт в carry chain (~8-10 LUT) |
| exp_norm_pre + exp_norm (замена RTZ exp_norm) | +9 | двойной инкремент экспоненты (round_carry) |
| Дополнительные FF | 0 | rounding — чисто комбинационный (`always @(*)`), новые регистры не нужны |
| **ИТОГО** | **+30** | |

### 3. `vhfastmulb16_mul_bf16_bf16_fp32_lat4` (BF16 x BF16 -> F32, exact, no rounding)

| Ресурс | Оценка | % от доступных (5,720 LUT6) |
|--------|--------|----------------|
| **LUTs** | **~420** (360–500) | **~7.3%** |
| FF (регистры) | **~130** | **~1.1%** |
| DSP48A1 | 0 | 0% |
| Block RAM | 0 | 0% |
| **Макс. частота** | ~160–180 MHz | — |

#### Распределение по подмодулям:

| Подмодуль | LUTs | FF | Примечание |
|-----------|------|-----|------------|
| `mul8x8_lat3` (4× `mul4x4_lat2` + CPA) | ~230 | ~80 | 3-ступенчатый множитель мантисс |
| `add8x8_lat2` | ~18 | ~19 | 9-bit add + 9-bit sub (bias 127) |
| `sign` | ~1 | 3 | 1 XOR, 3-ступенчатый конвейер |
| F32 pack (leading-one, shifter, exp unwrap) | ~120 | 0 | приоритетный шифратор + 24-bit сдвиг + mux |
| Top-level glue (классификация, flags, en_pipe) | ~50 | ~28 | NaN/Inf/Zero, задержки флагов |
| **ИТОГО** | **~420** | **~130** | |

#### Критический путь (оценка):

```
mul4x4_lat2 → mul8x8_lat3 CPA → leading-one → mant_norm shifter
→ exp_unb → F32 pack mux → output reg
```

Оценка ~6.0–6.5 ns (160–180 MHz). Точные значения требуют синтеза.

## Сравнение top-level модулей

| Модуль | LUTs | FF | Latency | Точность |
|--------|------|-----|---------|----------|
| `vhfastmulb16_rtz_lat3` | ~400 | ~150 | 3 | truncation (RTZ) |
| `vhfastmulb16_rne_lat3` | ~430 | ~150 | 3 | IEEE 754 RNE |
| `vhfastmulb16_mul_bf16_bf16_fp32_lat4` | ~420 | ~130 | 4 | exact BF16 product; RTZ for F32 subnormal |

RNE добавляет ~+30 LUTs относительно RTZ. F32-модуль использует
3-ступенчатый `mul8x8_lat3` и отдельную F32-упаковку, поэтому его
latency равна 4 тактам.

## Критический путь (Timing)

### RTZ:
```
mul4x4 (CSA) → mul_u8_u8_u16_lat2 CPA → exp_sum + man_msb → c_next mux → output reg
```
~5.5 ns (180 MHz)

### RNE:
```
mul4x4 (CSA) → mul_u8_u8_u16_lat2 CPA → man_shifted/G/R/S → RNE increment → exp_norm → c_next mux → output reg
```
~6.2 ns (160 MHz)

## Рекомендации по оптимизации

| Оптимизация | Экономия LUTs | Сложность |
|-------------|---------------|-----------|
| Перенести `mul_u8_u8_u16_lat2` на DSP48A1 | ~-200 LUTs (mul_u8_u8_u16_lat2 → ~0-10) | Замена структурного умножителя на DSP-инстанс |
| Убрать избыточные mux `*_exp_eff` (логически ≡ входу) | ~-30 LUTs | Простейшая правка |
| Объединить `except_lat2` + `flags_lat1` (флаги комбинационно) | ~-20 LUTs | Рефакторинг |
| **Потенциальный итог RTZ** | **~150-200 LUTs (~3%)** | |
