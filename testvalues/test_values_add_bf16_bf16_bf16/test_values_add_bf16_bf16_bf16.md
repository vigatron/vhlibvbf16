# BF16 Addition Test Vector Matrix (RNE / RTZ)

BF16 Addition: A + B = C

Формат bfloat16: [15] sign, [14:7] exp (bias = 127), [6:0] frac.

Округление:
- **RNE** — round-to-nearest-even (IEEE-754 default).
- **RTZ** — round toward zero (отсечение).

Примечания:
- Для точных результатов RNE = RTZ. Различие проявляется на неточных результатах
  (векторы №25, №26, №27, №28, №30: tie-to-even, отрицательное округление, overflow).
- Вектор №13: при RTZ переполнение даёт max finite `0x7F7F` (строгое следование IEEE-754),
  а не Inf `0x7F80`.
- Политика NaN: результат канонический `0x7FC0` (не проброс payload операнда).
