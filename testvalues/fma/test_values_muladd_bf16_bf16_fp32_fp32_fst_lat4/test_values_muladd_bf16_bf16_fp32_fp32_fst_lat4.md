# Тестовые векторы для `vhfastmulb16_muladd_bf16_bf16_fp32_fp32_fst_lat4`

Операция: `RESULT = SUMM + (VALA_BF16 × VALB_BF16)`, FP32 output, **RTZ** rounding, **FTZ** on inputs and output.

Контракт общий для `fst_lat8` и `fst_lat4`: значения `EXPECTED` совпадают побитово, различается только latency.

## Формат

Каждая строка: `VALA_BF16 VALB_BF16 SUMM_FP32 RESULT_FP32 # комментарий`

Все значения в шестнадцатеричном формате, без хвостовых пробелов.

## Правила FAST

| Случай | Результат |
|---|---|
| Любой NaN | canonical qNaN `0x7FC00000` |
| `Inf × finite` + `±Inf` | `±Inf` / qNaN при разных знаках |
| `Inf × 0` | qNaN |
| Subnormal вход BF16/FP32 | трактуется как 0 (FTZ) |
| Subnormal результат | `+0` (FTZ) |
| Переполнение FP32 | `±Inf` |
| Точная отмена `x + (-x)` | `+0` |
| Любой нулевой результат | `+0` (знак не сохраняется) |
